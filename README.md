# Awesome BLIT386 [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of great BLIT386 resources – the palette-first WebGPU retro engine for the web.

BLIT386 lets you draw with numbered palette colors instead of RGBA pixels and
animate whole scenes by rolling the palette.

## Official

- [Documentation](https://blit386.dev) – The official BLIT386 documentation site.
- [blit386](https://github.com/blit386/blit386) – The monorepo: the engine library
  ([npm](https://www.npmjs.com/package/blit386)), the `npm create blit386` scaffolder and `@blit386/kit`
  ([packages/create-blit386](https://github.com/blit386/blit386/tree/main/packages/create-blit386),
  [packages/kit](https://github.com/blit386/blit386/tree/main/packages/kit)), and interactive demo examples
  ([packages/demos](https://github.com/blit386/blit386/tree/main/packages/demos)).
- [GitHub organization](https://github.com/blit386) – All BLIT386 repositories.

## Games

- [Josepho](https://bzzzwa.github.io/josepho) – A platformer in the spirit of Mario and SuperTux on a tiny 192×108
  screen (by [@bzzzwa](https://github.com/bzzzwa)) – [repo](https://github.com/bzzzwa/josepho)
- [Blit386Blaster](https://justindjohnson.com/blitblaster) – Multiplayer asteroids in the browser, built with
  the BLIT386 engine, plus a tiny game-agnostic WebSocket relay. (by [@profexorgeek](https://github.com/profexorgeek)) –
  [repo](https://github.com/profexorgeek/Blit386Blaster)
- [Zoom Snake](https://zoomsnake.indiegames.cz) – A high-speed arcade take on Snake with a dynamic zoom that keeps you
  in the action (by [@chemix](https://github.com/chemix))
- [Hexarotato](https://hexarotato.indiegames.cz) – Hexarotato (by [@chemix](https://github.com/chemix))
- [Buckets Manager](https://basketball-manager.sigy.workers.dev) – Buckets Manager (by [@sigy](https://github.com/sigy))
  – [repo](https://github.com/sigy/buckets-manager)
- [Pong on BLIT386](https://bzzzwa.github.io/Pong-on-Blit386) – A Pong clone built with BLIT386
  (by [@bzzzwa](https://github.com/bzzzwa)) – [repo](https://github.com/bzzzwa/Pong-on-Blit386)
- [pinballpin](https://github.com/indiegames-cz/blit386-pinballpin) – A little pixel game built with BLIT386 (by [@chemix](https://github.com/chemix))
